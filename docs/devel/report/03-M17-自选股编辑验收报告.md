## 4. 实现决策与设计偏差登记（已回填设计基线 v6/v5）

1. **批量回执增 `op` 字段**：契约 `{code, ok, error}` 增 `op:add|remove`（同码同时出现在 add/remove 时可区分），纯增量不破坏契约；
2. **落库码为带前缀规范码**（如 `sh600519`）：qt.gtimg.cn 不识别裸码，裸码/大写输入按板块规则推导候选前缀逐个探测归一，写法变体幂等；
3. **错误码新增**：`BAD_CODE`（400，`details.reason ∈ {BAD_FORMAT, UNREACHABLE, SUSPENDED}`）、`QUOTE_SOURCE_ERROR`（503，探测网络异常）——已补登记 02 §5.4；
4. **停牌码拒加**：`last<=0 且 open<=0` 判停牌，复盘后方可收录（02 §6.12 口径）；
5. **suggest 缓存 TTL 30s**；上游故障返回空列表；同秒添加列表序以 code 升序兜底（added_at 秒级精度）。
