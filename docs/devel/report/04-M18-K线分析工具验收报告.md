## 3. 测试环境与证据快照

### 3.1 实测记录（8788 实例，`QTV_DB=local/data/qtvictory_test.db`，新代码重启后）

**冷热双态（T25）——四护栏测试证据**：

- 护栏① `kline_view` 合成：正常路径追加热 bar（30 万股 → 3000 手量纲锚定）；降级缺 OHLC / 停牌 / 冷序列已含当日三路径热 bar 缺席，不改动存量行；
- 护栏② 换日捕获源门禁：注入跨日快照序列——tencent/sina/eastmoney（OHLC 完整）捕获落库、anchor 恒不落、eastmoney 缺 OHLC 不落；捕获与 checkpoint 间幂等重跑不重复；
- 护栏③ 量纲锚定：`_to_lots` 与 `_to_shares` 互逆往返（sh/sz/688 三形态）；捕获 bar volume 与 ifzq 手数口径一致（14,200 手 ↔ 142 万股）；
- 护栏④ 深度约束：库存 3 根 → 拉取 800（默认）；库存 900 根 → 拉取 ≥ 900；配置 `QTV_KLINE_DEPTH=400` → 拉取 400；主源失败 → 东财回落 320。

**多周期 API（T26）——8788 实例实测**：

- `GET /api/market/kline?code=sh600519&period=day&limit=3` → 完结冷序列（末根 2026-09-20，close 1257.12）；
- `period=week&limit=4` → `['2026-08-28','2026-09-04','2026-09-11','2026-09-20']`（ISO 自然周周一界，date 取 period 末交易日）；
- `period=month&limit=3` → `['2026-07-31','2026-08-31','2026-09-20']`（自然月切分）；
- 聚合锚定：`week[-1]` 日期与日K同日 close 逐位一致；`period=minute/year` 仍 400 `BAD_REQUEST`（C013 口径保持）。

**前端（T27）**：

- 四周期 Tab（分时｜日K｜周K｜月K），周期选择经 `qtv_kline_period` 持久化，缓存键 `kline:{code}:{period}` 分键；
- 副图槽位 VOL｜MACD｜RSI｜KDJ（0.22 高度比，胶丸切换 + 30/70、20/80、零轴阈值虚线）；主图叠加 MA｜EMA｜BOLL 独立开关可同开（持久化 `qtv_kline_overlays`）；
- 图例：周期标签 + 日期 + OHLC + 涨跌幅 + 叠加指标当前值（逐线着色），副图指标名（参数）+ 当前值；
- 指标口径 D8 钉死：RSI=Wilder(14)（首值 SMA14）、MACD(12,26,9)、BOLL(20,2) 总体标准差、KDJ(9,3,3) 递推初值 50、EMA 种子=首值——golden vectors 六位精度与独立实现一致；
- §5.1 修订项落地：MA 透明度阶梯废止改色相阶梯（ind1/ind2/ind3/ind5），MA60 改 ind5 橙虚线。
