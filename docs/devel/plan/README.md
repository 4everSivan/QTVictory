# 开发计划与里程碑 (plan/)

> **定位**: Phase 1 开发阶段推进计划、里程碑拆解与进度跟踪矩阵
> **状态**: Phase 1 全部里程碑（M1–M16）**已全量完成并正式收口**。

---

## 1. 计划体系架构

`docs/devel/plan/` 承载了 QTVictory 模拟底座与观察员控制台建造期（0→1）的双线推进计划：
- **后端线（M1–M8）**：由 [00-总体开发计划.md](00-总体开发计划.md) 统一规划驱动；
- **前端线（M9–M16）**：由 [00-前端开发计划.md](00-前端开发计划.md) 承接并独立规划驱动。

每个里程碑（Milestone）明确定义了上游依赖、所辖任务（关联 [task/](../task/)）、退出条件（Exit Criteria）与验收要点。
