## 1. 目标

交付**可构建的空系统**：Vite + React 18 + TypeScript（strict）工程骨架、01 §10.1 目录映射、§3 设计令牌与双主题体系、§2.2 一屏五区栅格外壳、vitest 测试基建与环境变量注入。本里程碑不含任何数据对接与业务组件。

## 2. 退出条件

- [x] `npm run build` 零报错（TS strict），`npm run dev` 空壳可启动；
- [x] 目录结构与 01 §10.1 映射逐项一致（`components/{charts,panes,traders}`、`api/` 占位）；
- [x] §3.2 Nothing 令牌全量落 CSS 变量，语义色纪律（组件选择器不声明 color）落实；
- [x] 双主题（Nothing 基线 / 终端深蓝备选）切换即时生效、刷新保持、`window.__THEME` 可读；
- [x] 栅格几何符合 §2.2（48px 顶栏 / 236px Dock / 262·324 侧栏 / 左栏 55·44，含 ≤1180px 降级）；
- [x] 示例测试（组件 + 纯函数各一）全绿（vitest 9 用例）。

## 4. 风险与对策

| 风险 | 对策 |
|---|---|
| 原型为 UMD React + Babel standalone，直接搬运会引入非工程化隐患 | 以 TS 重写为硬约束；原型仅作样式/几何参照（T15 范围声明） |
| 字体三族（Doto/Space Grotesk/Space Mono）外链加载阻塞或抖动 | 自托管或 font-display 策略在 T15-2 内定夺并记录；断网降级不白屏 |
| 语义色特异性坑（§3.2 v1 固化）复发 | 代码评审对照"组件选择器禁止声明 color"逐条核对 |
