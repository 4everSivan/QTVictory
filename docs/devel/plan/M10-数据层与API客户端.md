## 2. 退出条件

- [x] 类型层覆盖 01 §7.2 映射表全部端点与五类 WS topic；WS 帧运行时守卫就位；
- [x] 对真实后端冒烟全绿：`/api/session`、`/api/market/quotes`、`/api/traders` REST 拉取（smoke.mjs 11 项）；

- [x] 服务端状态 hooks 就位：同一 topic 多组件订阅不重复开连接/订阅帧（ws.test.ts 断言）。
