交付行情展示三件套与顶栏市场状态区：自选股列表（§4.2）、个股头部（§4.4）、盘口五档 + 逐笔成交（§4.6，含 `DEGRADED` 降级条）、市场状态与沪深300 胶囊（§4.1 左段）。全部经 M10 数据层消费真实行情（REST 初始 + `quotes` topic 增量），选中标的联动全站。

## 2. 退出条件

- [x] 自选股列表版式/闪动/选中白条/涨跌统计条按 §4.2 落地，tick 增量更新不整行重排；
- [x] 个股头部 Doto 36px+ 现价 + 8 项指标 chips 与后端字段逐项一致（§4.4）；
- [x] 盘口五档 + 逐笔为后端真实快照（合成深度废止；逐笔由 ΔV 派生——T17 变更记录），fallback 时 DEGRADED 条正确显隐（§4.6）；
- [x] 四种会话状态胶囊正确（交易中/已收盘/集合竞价/已降级），指数"9px 标签 + 15px 数值"同构单元（§4.1 v2.1）；
- [x] 标的切换无旧数据残留/无订阅泄漏，kline/minute 预取可供 [T18](../task/T18-图表组件.md) 直读。
