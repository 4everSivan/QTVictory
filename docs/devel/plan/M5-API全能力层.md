## 1. 目标

系统全部能力经 REST + WS 暴露（API-first，§4.1）：§5.2 全端点、订阅式 WS 推送、鉴权/幂等/限速/审计四横切中间件、OpenAPI 全覆盖。**本里程碑完成后，前端 v2 改造可并行启动**（对接口径见 [01-前端设计方案](../design/01-前端设计方案.md) §7）。

## 2. 退出条件

- [ ] REST 端点与 §5.2 表逐项对照勾稽（含请求/响应示例一致性）；
- [ ] 鉴权矩阵通过（§6.12）：有/无 `QTV_API_KEY`、`QTV_PUBLIC_READ`、WS 握手 `?key=`；
- [ ] 幂等重放通过：重复 `Idempotency-Key` 返回首次结果；请求体不一致返回 `DUPLICATE_REQUEST`；
- [ ] 限速：令牌桶 20 req/s，超限 `429` + `Retry-After`；
- [ ] 审计断言通过：全部非 GET 落 `audit_log`（失败请求与免鉴权模式同样记录，不含密钥）；
- [ ] WS 集成测试：五类 topic 订阅/推送正确，`traders` 节流 2s 生效；
- [ ] OpenAPI 文档完整（全部端点 + pydantic 模型）。
