## 1. 目标

计划体系接入运行时：计划与条件单 CRUD、PlanEngine 每 tick 触发评估、风控钩子、策略调度（Strategies 输出经围栏过滤后执行），订单以 `origin=plan/strategy` 进入交易链路并推送事件。

## 2. 退出条件

- [ ] 触发 → 下单（走 T07 校验链，含 PLAN 约束）→ 成交 → WS `plans` 事件全链路集成测试通过；
- [ ] 四类触发器在真实 tick 序列下一次性触发（防重复）；
- [ ] 策略围栏四道闸（池内→预算→仓位→单笔）在集成环境逐闸拦截用例通过；
- [ ] 日亏损熔断：计划转 paused + `risk_halt` 事件；
- [ ] 策略调度：`traders.status=paused` 的交易员不产出任何意图；
- [ ] `gtc` 条件单日切续期、`day` 条件单日终撤销。
