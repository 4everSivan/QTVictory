## 1. 目标

落地自选股增删能力（来源：future.md FT-0001，2026-09-17 登记，[M16 终验报告 §7](../report/02-M16-前端验收报告.md) 输入）：后端新建 WatchlistService 与 watchlist 端点组（自选集观察员级全局唯一、关注集并入第四支、添加即拉日K、批量逐码校验部分应用）；前端自选股列表支持 "+" 弹层联想添加、hover 删除、自选置顶倒序、动态项不可删。

## 2. 退出条件

- [x] 后端端点契约实测：`GET /watchlist`（倒序）、`PUT/DELETE /watchlist/{code}`（单码幂等）、`POST /watchlist/batch`（逐码校验/部分应用/逐码回执）、`GET /market/suggest`（联想代理）；
