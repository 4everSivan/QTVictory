## 1. 目标

对照 02 §6.12 全表做终验收：单测清点补全、API 完备性与鉴权矩阵、UI↔API 对照清单（防能力漂移）、生命周期全流转、性能基准；产出验收报告并补全 README 快速开始命令（Phase 1 首个可运行版本）。

## 2. 退出条件

- [ ] §6.12 逐项核对表全绿（引擎/计划/策略/鉴权/幂等/限速/审计/导出/生命周期）；
- [ ] UI↔API 对照清单：每项 UI 能力（对照 [01 §7.2](../design/01-前端设计方案.md)）有对应通过的 API 用例；
- [ ] 性能基准达标：64 交易员 × 2 计划 × 5 条件单单 tick 评估 < 50ms；导出 1 万行 < 2s；tick → 撮合/计划 → WS 广播 < 200ms（本机）；REST P95 < 50ms；
- [ ] 验收报告归档（`docs/devel/report/`，随报告创建目录）；
- [ ] README「快速开始」命令补全。
