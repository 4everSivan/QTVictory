## 1. 目标与范围

收尾三块展示能力：收益分析（真实 `equity_snapshots` 序列，v1 布朗桥示意废止）、交易计划面板（计划卡 + 条件单列表 + 新建条件单表单）、导出菜单（浏览器直接下载）。计划调度与触发全在后端（02 §4.4/§6.7），本任务为纯展示 + 表单提交。

明确不做：审计查看界面（01 §4.1"可后置"）——本任务结束后仍后置，收口前在 T22 范围声明中登记为已知未做项。

## 2. 任务明细

### T21-1 收益分析 Tab
- **内容**：§4.9：统计卡与净值曲线版式 v1 不变，数据改接后端真实 `equity` 序列（每日收盘快照）；快照不足 2 个交易日时指标显示 `--` 并提示"数据积累中"；净值曲线消费 [T18-4](T18-图表组件.md) 组件，数据编排（`/traders/{id}` equity 端点 → 组件 props）在本任务落地；接 [T20](T20-交易链路.md) 的 Dock 第四 Tab。
- **交付物**：`components/panes/AnalyticsTab.tsx`。
- **验收标准**：指标口径以后端 metrics 为准逐项一致；<2 日空态正确；跟随当前交易员切换（§2.1）。

### T21-2 计划面板
- **内容**：§4.10〔v2 新增〕：**计划卡**——状态 / 预算水位条 / 风控参数 / 执行进度 / 目标仓位偏差；**条件单列表**——触发器 → 动作 → 状态（waiting/triggered/filled）；**新建条件单表单**——四类触发器（价格穿越/当日涨跌幅/定时/均线交叉）、动作（方向/数量或仓位比例/限价市价）、有效期 day/gtc；数据 `/traders/{id}/plans` + `/plans/{id}/entries` + `plans` topic（后端 [T11](T11-计划服务接入.md) 推送 `entry_triggered / risk_halt / plan_done`）；挂载点：详情弹窗计划页签容器（[T19-4](T19-交易员模块.md) 预留）。
- **交付物**：`components/traders/PlanPanel.tsx`（卡 + 列表 + 表单）。
- **验收标准**：计划卡五要素齐全；条件单状态流转经 `plans` topic 实时呈现；表单四类触发器字段切换正确且提交接 API；风控事件（risk_halt）有醒目呈现。

### T21-3 导出菜单
- **内容**：§4.10〔v2 新增〕：**类型**（成交/委托/持仓/净值/计划）× **格式**（CSV/JSON）× **时间区间**，菜单选择后直接触发浏览器下载（`/traders/{id}/export`，依赖 [T16-2](T16-数据层与API客户端.md) blob helper）；菜单入口：侧板行管理菜单"导出"（[T19-2](T19-交易员模块.md)）+ Dock 区入口。
- **交付物**：导出菜单组件 + 下载编排。
- **验收标准**：5 类型 × 2 格式组合全部可下载且内容字段与后端一致；时间区间参数正确传递；下载失败有 Toast 反馈。

### T21-4 计划详情联动与收尾
- **内容**：详情弹窗计划页签内容装配（T19-4 容器 + T21-2 面板）；`plans` topic 订阅生命周期（打开时订阅、关闭退订）；与 [T20-5](T20-交易链路.md) Toast 体系汇接（计划触发/熔断事件入 Toast）。
- **交付物**：联动装配 + 集成验证。
- **验收标准**：弹窗打开期间计划状态实时刷新、关闭后无订阅泄漏；计划事件 Toast 呈现与 Dock 数据一致。
