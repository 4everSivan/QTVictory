## 1. 目标与范围

前端 K 线分析界面：图表数据**全部**来自后端 `GET /market/kline?period=day|week|month`（`kline_view` 冷热合成序列，当日 bar 由后端提供，前端零合成零聚合）；分时走 `/market/minute` 不变。四周期 Tab、单副图槽位（VOL/MACD/RSI/KDJ）、主图叠加（MA/EMA/BOLL）、指标色阶令牌、图例与 golden vectors。

明确不做：画线工具（趋势线/水平线/斐波那契——二期占位 disabled）；后端数据与聚合（T25/T26）；§5.1 既有交互口径变更（对周 K/月 K 同样适用，不改语义）。

## 2. 任务明细

### T27-1 周期 Tab 与数据层
- **内容**：`ca-tabs` 胶丸扩为 分时｜日K｜周K｜月K 四枚；选中周期经 `lib/storage.ts` 持久化；kline 缓存按 period 分键；分时态隐藏叠加与副图控件。
- **交付物**：周期 Tab + 数据层接线（含单测）。
- **验收标准**：周期切换正确请求对应 `period`；分时/日K 既有行为零回归（C018 缓存刷新策略不变）。

### T27-2 KLineChart 泛化与副图槽位
- **内容**：`KLineChart` 泛化副图槽位（高度比例 0.20 → 0.22）；VOL｜MACD｜RSI｜KDJ 悬浮胶丸切换（副图右上、半透明底、贴被控对象）；RSI 画 30/70、KDJ 画 20/80 阈值虚线；MACD 零轴虚线，柱状图涨跌红绿。
- **交付物**：泛化图表组件 + 副图渲染。
- **验收标准**：副图切换与阈值线渲染符合 §5.5 D2/D3；红绿严格专属涨跌语义（量柱/MACD 柱），指标线禁用红绿。

### T27-3 主图叠加与图例
- **内容**：MA｜EMA｜BOLL 独立开关（顶栏第二胶丸组，可同开）；图例——主图左上日期+OHLC+涨跌幅+各叠加指标当前值（tspan 逐线着色），副图左上指标名(参数)+当前值；无光标显最新根，十字光标跟随。
- **交付物**：叠加层与图例。
- **验收标准**：D4/D5 口径；MA60 由灰虚线改 ind5 橙虚线、MA 透明度阶梯废止改色相阶梯（§5.1 修订项随本卡落地，浅色对比度问题消解）。

### T27-4 指标纯函数与色阶令牌
- **内容**：`charts/math.ts` 增 `ema/macd/rsiWilder/boll/kdj` 纯函数（null 语义对齐 `maSeries`，窗口不足返回 null）；口径钉死——RSI=Wilder(14)、MACD(12,26,9)、BOLL(20,2) 总体标准差、KDJ(9,3,3) 递推初值 50、EMA 种子=首值；**golden vectors** 固定输入→期望输出前端单测断言；新增令牌 `--ind3 紫`/`--ind4 青`/`--ind5 橙`（深/浅两套值随 §3.2 令牌表落地），ind1/ind2 复用既有。
- **交付物**：纯函数 + golden vectors 单测 + 令牌。
- **验收标准**：D6/D8 口径；与 TA-Lib 的 SMA 种子差异在 golden vectors 中显式钉死。

### T27-5 交互与性能回归
- **内容**：§5.1 全交互定稿（滚轮 ×1.18、30~N、右端锚定、拖拽平移、双击复位、十字光标、仅渲染可见区间）对周 K/月 K 同样适用；§5.4 性能口径不变；E2E 回归。
- **交付物**：回归测试。
- **验收标准**：`npm test` / `npm run build` / `node frontend/scripts/e2e.mjs` 全绿。
