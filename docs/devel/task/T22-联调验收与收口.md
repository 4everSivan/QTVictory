## 2. 任务明细

### T22-1 UI↔API 对照终验
- **内容**：以 01 §7.2 映射表为清单逐项验证"每个 UI 区域的数据有对应的真实端点/订阅用例"（含 v2 新增：切换器/计划面板/导出/市价类型/部分成交）；另核 01 §12 范围声明：自选股编辑、移动端、浅色模式、审计入口四项为登记在案的已知未做项。
- **交付物**：对照清单终版（随报告归档）。
- **验收标准**：无缺口；发现漂移回填对应 task 变更记录。

### T22-2 端到端交易链路演练
- **内容**：真实后端全链路：创建交易员（模板+任意资金）→ 买入（限价/市价两类型）→ 部分成交呈现 → 撤单 → T+1 可卖口径 → 卖出 → 费用/冻结核对；v2 新增组件逐一实测（管理菜单/创建对话框/计划面板/导出菜单/确认弹窗身份标注）；双主题各跑一遍零报错。
- **交付物**：演练记录（步骤 ↔ 结果 ↔ 截图）。
- **验收标准**：全链路通过；每步回执与 UI 呈现一致；双主题零 console 报错。

### T22-3 连接策略与降级演练
- **内容**：§7.3 全路径：启动序（REST 全量 → WS 增量）→ 断线重连（REST 拉回再续订）→ WS 不可用轮询降级（quotes 3s / traders 5s）→ 行情三级降级徽标映射（`source/live/fallback` → 顶栏 + 盘口 DEGRADED）；WS 恢复自动切回。
- **交付物**：降级路径演练记录。
- **验收标准**：四条路径逐条演练通过；降级期间数据连续性肉眼无断档；恢复后无订阅泄漏/重复。

### T22-4 几何与性能校验
- **内容**：§2.2 栅格几何校验（1560×940 参考几何：48px 顶栏 / 236px Dock / 262·324 侧栏 / 左栏 55·44 分割，含 ≤1180px 降级断点）；§4.1 v2.1 字号三档纪律抽查（15 数据 ≈ 14 品牌 ＞ 12 交互 ＞ 9 微标签，徽章归标签档）；§5.4 图表测量三路径生效核对；大窗口拉宽时五指标等分行为。
- **交付物**：几何校验表（实测值 ↔ 设计值）+ 截图。
- **验收标准**：几何偏差 ≤1px；字号档位抽查无越档；图表 resize/兜底路径各验证一次。
