## 1. 目标与范围

落地冷热双态 bar 模型（Q12 决议）：**冷 bar** = `klines` 表完结 bar（语义不变，`price()`/PlanEngine `ma_cross`/回测直读纯冷序列）；**热 bar** = MarketBus 快照的当日累计态（vendor 全 tick 口径，非本地 3s 采样），盘中即当日 bar；**统一视图 `kline_view`** = 冷 ∪ 热（交易日未完结时）纯函数，降级档缺当日 OHLC 时热 bar 缺席、诚实少最后一根，不造假 bar。换日捕获自沉淀（与 C012 同构对称）+ 校准重拉兜底 + qfq 前复权口径锚定 + 日 K 引导深度 320 → 800 可配。

明确不做：week/month 聚合与 `period` 枚举放行（归 [T26](T26-多周期聚合与K线API.md)）；前端图表（归 [T27](T27-K线图与指标副图.md)）；§3.11 冷热双态之外的数据底座功能（无）。

## 2. 任务明细

### T25-1 kline_view 冷热合成纯函数
- **内容**：`klines` 完结冷序列 ∪ MarketBus 快照当日热 bar 的纯函数合成（交易日未完结时含热 bar；已完结则等价冷序列）；降级源缺当日 OHLC 时热 bar 缺席，视图少最后一根。
- **交付物**：`kline_view` 纯函数 + 单测。
- **验收标准**：四护栏①——正常/降级缺 OHLC/停牌/停机跨换日→重拉兜底四条路径单测；触发域（`price()`/`ma_cross`）保持直读纯冷序列，双读者路径语义零变化。

### T25-2 Quote 领域语义落地
- **内容**：将"快照 open/high/low/last/cum_volume 为上游维护的当日累计态（Quote 即当日 bar 聚合态）"写进 §3.4 领域模型实现，端点级不做任何"注入"。
- **交付物**：Quote 领域模型注释/结构随实现同步。
- **验收标准**：实现与 02 §3.4 口径一致；既有快照链路测试全绿。

### T25-3 换日捕获自沉淀
- **内容**：`_ingest` 换日检测处、快照被新日数据覆盖**之前**，将完结热 bar 落库；落库门禁按源分级——tencent/sina（live 完整档）必落、eastmoney（真实价但字段可能不全）视 OHLC 有效性、**anchor 恒不落**；并入 day-cut 既有 `daycut:{d}:{step}` 断点机制，幂等可重入。
- **交付物**：换日捕获逻辑 + 断点重入测试。
- **验收标准**：四护栏②源门禁断言；崩溃于捕获与 checkpoint 之间幂等重跑不重复落库、不丢 bar。

### T25-4 校准重拉兜底
- **内容**：跨换日停机错过捕获、历史缺口、除权后 qfq 重锚三种情形由上游重拉覆盖（复用 C014 `_fetch_daily_chain` 腾讯 ifzq → 东财 push2his 兜底链，`upsert_klines` 幂等）；**重拉深度 ≥ 库存深度**，`QTV_KLINE_DEPTH` 同时约束两者；上游为最终权威。
- **交付物**：校准重拉逻辑 + 深度约束测试。
- **验收标准**：四护栏④深度约束断言；单码失败仅告警不阻断（与 C014 同口径）。

### T25-5 日K引导深度可配
- **内容**：引导深度 320 → 800，经 `QTV_KLINE_DEPTH` 环境变量可配（默认 800，上限 le=800）；单源拉取失败回落 320 不阻断引导链。
- **交付物**：配置项接线（02 §6.10 已有登记）+ 回落链路测试。
- **验收标准**：深度引导回落链路（800 失败 → 320）测试；存量库加深 `upsert` 幂等无破坏。

### T25-6 量纲锚定与复权口径
- **内容**：日 K 全链路保持前复权（腾讯 ifzq `qfq` / 东财 push2his `fqt=1`，C008 已对齐量纲）；收盘快照 `cum_volume` 与 ifzq 同日 volume 一致性实测断言（手/股口径）。
- **交付物**：复权锚定测试。
- **验收标准**：四护栏③量纲一致性断言；后续新增行情源必须同口径并加测试锚定（设计纪律）。
