## 1. 目标与范围

前端自选股列表编辑能力："+" 弹层联想添加、hover 删除（仅自选项）、自选置顶按添加时间倒序、动态项不可删；数据接 T23 端点组，行情刷新链路不变。

明确不做：后端服务与端点（归 [T23](T23-自选股服务与接口.md)）；列表结构/栅格/闪动等 v1 基线样式改动（§4.2 明确结构不变）。

## 2. 任务明细

### T24-1 数据层与列表编排
- **内容**：watchlist API 客户端封装（`GET /watchlist`、`PUT/DELETE /watchlist/{code}`、`POST /watchlist/batch`、`GET /market/suggest`）；列表成员编排：自选集置顶（addedAt 倒序）+ 动态项（持仓 ∪ 计划池 ∪ 指数中非自选项，保持后端关注集原顺序）；自选/动态项归属判定驱动删除 affordance。
- **交付物**：API client 方法 + 列表编排逻辑（含单测）。
- **验收标准**：编排顺序与归属判定单测覆盖（自选置顶倒序、删除后引用项回落动态区）。

### T24-2 添加弹层与联想
- **内容**：面板头部 "+" 弹层：输入框 + 联想下拉（`/market/suggest`，输入防抖，键盘上下选择 + 回车确认）；确认后 `PUT /watchlist/{code}`，成功即入列置顶、失败转 Toast 体系。
- **交付物**：添加弹层组件。
- **验收标准**：联想结果渲染与键盘交互正确；添加成功/失败两路径 UI 反馈符合 §4.2。

### T24-3 删除交互
- **内容**：hover 自选行尾显现删除钮（动态项无此 affordance）；`DELETE /watchlist/{code}` 幂等；删除后仍被持仓/计划引用的码自动落入动态项区保留展示。
- **交付物**：行尾删除钮与删除编排。
- **验收标准**：动态项不可删（无入口）；删除后列表重排正确。

### T24-4 联调与 E2E
- **内容**：真实后端全链路联调（添加 → quotes 出现该码 → 日K 历史可渲染 → 删除 → 引用保留判定）；Playwright E2E 用例补入 `frontend/scripts/e2e.mjs`。
- **交付物**：E2E 用例与联调记录。
- **验收标准**：`npm test`、`npm run build`、`node frontend/scripts/e2e.mjs` 全绿；真实后端冒烟通过。
