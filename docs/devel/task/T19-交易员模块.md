## 1. 目标与范围

交付观察员对交易员的全部 UI 能力（§8 纯展示 + 管理操作入口）：顶栏当前交易员切换器与五指标带、交易员侧板与管理菜单、创建/编辑对话框、详情弹窗（统计/净值/持仓/最近成交/计划页签）。切换器为全站作用对象开关——持仓/委托/成交/收益分析与下单面板全部跟随（§2.1 v2 语义），该跟随语义在本任务内全局生效。

明确不做：v1 原型的前端策略引擎（`traders.jsx` 的 ACT/调度，§8 已废止）；审计查看界面（§4.1"可后置"，归 T21 范围说明）。

## 2. 任务明细

### T19-1 顶栏装配与当前交易员切换器
- **内容**：§4.1：品牌区/市场状态/指数段与 [T17-5](T17-行情面板.md) 汇接；**当前交易员切换器**〔v2 新增〕：胶囊式下拉（名称 + 模式徽标 manual/strategy + 总资产速览）；切换后顶栏五指标（总资产/持仓市值/可用资金/当日盈亏/总收益率）与 Dock/下单面板全部跟随；无交易员空态按钮"创建交易员"直达对话框；**五指标均分数据带**：`flex:1` 等分剩余宽度、项间 1px `--line` 细线（§4.1 v2.1）；字号纪律三档（15px 数据档 `tabular-nums` ≈ 14px 品牌 ＞ 12px 交互档 ＞ 9px 微标签档，徽章 8–10px 归标签档）；时钟。
- **交付物**：`components/traders/TraderSwitcher.tsx` + 顶栏装配 `components/panes/Topbar.tsx`。
- **验收标准**：切换器下拉数据来自 `/traders`；切换后全站数据带/Dock/下单面板作用对象变更（联动断言）；窗口拉宽五指标等距拉开不新增元素；空态引导正确。

### T19-2 交易员侧板
- **内容**：§4.3：表头"交易员 (n)" + 状态徽标 + 「＋ 新建」按钮；行结构 `16px 1fr 56px 52px`（排名/姓名/策略/收益率）、"你的账户"概念移除（manual 徽标普通行）；行尾悬停管理菜单：编辑 / 暂停·恢复 / 注资 / 导出 / 删除（软删，二次确认）；底部单行动态流（`events` topic）；空世界首启空态引导"从模板创建"〔v2 新增〕。
- **交付物**：`components/traders/TraderBoard.tsx`。
- **验收标准**：排行按总收益率排序（后端 `/traders` 口径）；管理菜单五项操作全部接 API 且成功/失败有反馈；动态流随 `events` 追加；空态引导直达创建。

### T19-3 创建/编辑对话框
- **内容**：§4.10〔v2 新增〕：字段——名称 / 模式（手动｜策略）/ 策略模板选择（`GET /api/templates` 8 示例 + 参数表单，按参数 schema 动态渲染）/ **任意初始资金** / 可选计划速设（标的池 + 止损止盈 + 日亏损上限）；编辑态支持改名、改参数；提交 `POST /traders` / 对应更新端点；表单校验（必填/数值范围）就地文案。
- **交付物**：`components/traders/TraderFormDialog.tsx`。
- **验收标准**：模板参数 schema 驱动渲染（改模板即换表单）；创建成功后新交易员出现在侧板并被选中；编辑回显正确；非法输入阻止提交并给文案。

### T19-4 详情弹窗
- **内容**：§4.10：720px 弹窗五区——统计卡（后端 metrics）/ 净值曲线（消费 [T18-4](T18-图表组件.md) 组件，数据本任务接 `/traders/{id}` equity 序列）/ 持仓 / 最近成交 / **计划页签**（内容归 [T21](T21-计划收益与导出.md)，本任务留容器与页签骨架）。
- **交付物**：`components/traders/TraderDetailDialog.tsx`。
- **验收标准**：五区数据均来自后端真实端点；页签切换状态保持；弹窗打开期间数据经 `trader:{id}` topic 增量刷新。

### T19-5 生命周期操作全流转
- **内容**：创建 / 改名改参 / 暂停·恢复 / 注资 / 重置（重置确认弹窗，§4.10）/ 软删 / 关闭 全流转接 API；`traders`（节流 2s）+ `trader:{id}` + `events` topic 驱动各视图刷新；`trader:{id}` 按当前选中动态订退（依赖 [T16-3](T16-数据层与API客户端.md)）。
- **交付物**：生命周期操作模块 + 集成验证。
- **验收标准**：全流转逐步操作成功且视图一致刷新（无 stale）；删除需二次确认且软删语义呈现；`trader:{id}` 无泄漏（切换/删除后退订）。
