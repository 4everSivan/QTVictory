## 1. 目标与范围

交易时段状态机、日切全序列（幂等可重入）与公司行动处理（02 §3.9 / §6.4 / §6.6）。日切序列是系统的"心跳收口"：日终撤单、收盘快照、公司行动、T+1 重置、日K增量、分钟线落库、计划到期、日期推进。

## 2. 任务明细

### T08-1 交易时段状态机
- **内容**：基于 MarketBus 快照时间与新鲜度判定状态：交易中 / 已收盘 / 集合竞价（9:15–9:25 / 14:57–15:00）/ 已降级；提供 `GET /session` 的 `{state, tradingDate}` 数据源（端点在 T09）；集合竞价子窗口（9:20–9:25 禁撤）联动 [T07-3](T07-交易服务.md)。
- **交付物**：状态机模块。
- **验收标准**：一个完整交易日的状态序列测试（含午休）；降级状态下状态标注正确。

### T08-2 日切序列编排（幂等可重入）
- **内容**：按 §6.4 固定顺序编排：日终撤单（全体交易员日内订单 + `tif=day` 条件单）→ 收盘快照（调用 [T12-1](T12-统计服务.md) 钩子）→ 公司行动处理（T08-3）→ T+1 重置（today_bought 清零）→ 日K增量（调用 [T06-4](T06-行情服务.md)）→ 当日分钟线落库（[T06-5](T06-行情服务.md)）→ 计划到期检查（[T11](T11-计划服务接入.md) 钩子）→ 交易日期推进（`sync_state`）。每步落检查点，支持中断续跑。
- **交付物**：日切编排器 + 检查点机制。
- **验收标准**：任一步骤中断后重跑，全部步骤恰好执行一次（幂等可重入断言）；顺序与 §6.4 一致。

### T08-3 公司行动处理
- **内容**：除权日处理 `corporate_actions`（T06-6 采集）：**现金分红** `现金 += 登记日持仓 × 每股派息 × (1 − QTV_DIVIDEND_TAX)`（默认税率 10%，`0` 即免税；差异化持有期计税不做——已知简化）；**送转股** `股数 = 原股数 × (1 + 送股比 + 转增比)`（零股并入）、`avg_cost = 原成本总额 / 新股数`、到账股份**不占用 today_bought**（除权日即可卖出）；除权日 `prev_close` 直接采用快照除权参考价。
- **交付物**：公司行动处理器。
- **验收标准**：§6.12 公司行动断言——分红入账税率、送转股数与成本摊薄、到账当日可卖；红利税配置为 0 的免税用例。

### T08-4 公司行动事件留痕
- **内容**：分红/送转入 `trader_events`（`action=dividend/transfer`），持仓与现金变更随快照可追溯（§6.6）。
- **交付物**：事件写入。
- **验收标准**：事件内容与账户变更核对一致；事件可在动态流中查询（[T05-5](T05-交易员服务.md)）。
