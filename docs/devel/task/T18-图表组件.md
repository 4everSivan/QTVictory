## 1. 目标与范围

交付三个纯 SVG 主题化图表组件（§5 全章）：日 K（§5.1 定稿全交互）、分时（§5.2）、净值曲线（§5.3，含多交易员对比 TradersCurve 可选组件）；含图表基础设施（渲染框架 + §5.4 三重测量 + 主题钩子消费）。图表为**纯展示组件**：数据经 props/T16 缓存注入，不含数据获取逻辑（净值数据接入编排归 T21）。

## 2. 任务明细

### T18-1 图表基础设施
- **内容**：纯 SVG 渲染框架（坐标映射、DPR 处理、resize）；主题消费 `window.__THEME`（T15-3 钩子）——配色/线宽/点阵底随主题切换；§5.4 三重测量：ResizeObserver + 直接测量 + 定时/resize 兜底（嵌入式 WebView RO 可能不触发，必须实现兜底）；点阵网格底与加载态（§3.2）。
- **交付物**：`components/charts/` 基础设施（`ChartFrame` 等）。
- **验收标准**：双主题下图表配色正确切换；容器尺寸变化图表正确重排（三路径各自有测试）；无数据时显示点阵加载/空态。

### T18-2 日 K 组件
- **内容**：§5.1 全交互规格：默认 90 根可见；滚轮缩放 30~N（×1.18）/ 拖拽平移 / 双击复位；padL 4 / padR 58 / padT 26 / 日期轴 16；成交量子图 20%；MA5/10/20/60 透明度阶梯（100%/55%/32% + MA60 灰虚线）；最新价虚线 + 右轴色块标签；十字光标 + OHLC 信息条；数据支持后端全量日 K（`period=day`，经 T17-4 预取）。
- **交付物**：`components/charts/KLineChart.tsx`。
- **验收标准**：交互逐项按 §5.1 验收（缩放比例/平移边界/复位）；缩放平移数学纯函数单测覆盖；性能：全量日 K（数千根）交互无掉帧感（本机实测记录）。

### T18-3 分时组件
- **内容**：§5.2 规格：242 槽；左右双轴（价格/百分比，相对昨收着色）；价格线涨跌色 + 5% 面积渐变；VWAP 均价线灰虚线；昨收基准线；量柱子图 22%；`components/charts/` 下交付。
- **交付物**：`components/charts/MinuteChart.tsx`。
- **验收标准**：242 槽对齐交易时段；双轴刻度/着色正确；VWAP 与后端/前端计算口径核对（实现时记录口径）。

### T18-4 净值曲线组件
- **内容**：§5.3 版式：归一化百分比、双线（账户/基准）、悬停浮签（日期/账户/基准/超额）；多交易员对比 TradersCurve 大屏组件保留为可选组件（v1 原型对应物，TS 化重写）；空态：快照不足 2 个交易日显示 `--` + "数据积累中"（§4.9 口径）。
- **交付物**：`components/charts/EquityCurve.tsx` + `TradersCurve.tsx`（可选）。
- **验收标准**：归一化计算纯函数单测；浮签字段与 §5.3 一致；<2 日空态正确；对比模式多交易员线条可区分（单色系内靠线型/透明度，遵守 §3 单色纪律）。

### T18-5 图表区版式集成
- **内容**：§4.5 v1 定稿：Tab 胶丸（分时/日K 切换）、图表框点阵底、右上操作提示文案；该区属 center 主体，本任务交付容器 + 组件装配（数据由 T16/T17 缓存直读）。
- **交付物**：`components/panes/ChartArea.tsx`。
- **验收标准**：Tab 切换图表即时互换且各自状态（缩放/平移）保持；操作提示与 §4.5 一致。
