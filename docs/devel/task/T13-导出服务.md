## 1. 目标与范围

按交易员导出五类数据 × 两种格式 × 时间区间过滤，同步流式下载（02 §6.8，Q5 决议：不做异步任务；升级触发条件——单次 >10 万行或响应 >5s——记录实测值到 [T14-5](T14-验收与性能基准.md) 基准）。

## 2. 任务明细

### T13-1 导出框架
- **内容**：`GET /traders/{id}/export?type=trades|orders|positions|equity|plans&format=csv|json&from=&to=`；参数校验（非法 `EXPORT_RANGE_INVALID`）；`Content-Disposition` 附件；同步流式输出。
- **交付物**：导出端点服务。
- **验收标准**：5 类型 × 2 格式全组合请求成功；非法参数错误码用例；响应头断言。

### T13-2 CSV 规范
- **内容**：UTF-8 **with BOM**（Excel 兼容）；列定义 = §3.8 导出表（trades：时间/代码/名称/方向/价/量/费用/已实现盈亏/origin；orders：含状态/成交价/origin/条件单回链；positions：快照式含可卖/浮盈；equity：日期/总资产/现金；plans：含状态与触发记录）；金额两位小数、**不加千分位**；流式生成（不整表驻留内存）。
- **交付物**：CSV 生成器。
- **验收标准**：字段/顺序与 §3.8 表一致；Excel 打开无乱码（BOM 验证）；大结果集内存占用平直。

### T13-3 JSON / NDJSON
- **内容**：默认 JSON 数组；`?stream=true` 可选 NDJSON（逐行对象）。
- **交付物**：JSON 生成器。
- **验收标准**：两种格式可解析；NDJSON 逐行完整性。

### T13-4 区间过滤
- **内容**：`from/to` 基于 `trades.traded_at` / `orders.created_at` / `equity.date`；`positions` / `plans` 为当前时点快照（不参与区间过滤，§6.8）。
- **交付物**：过滤逻辑。
- **验收标准**：边界用例（恰好等于 from/to 的记录包含性明确并测试）；无区间参数 = 全量。
