## 1. 目标与范围

真实行情接入与规范化输出（02 §3.4 / §6.5）：腾讯源轮询、三级降级链、MarketBus 内存最新档、日K全量+增量、分钟线逐日累积、公司行动采集、交易日历推定、关注代码集动态。**规则**：行情失败不阻断交易（§2.3），新鲜度标注透出。

## 2. 任务明细

### T06-1 腾讯 QuotePoller
- **内容**：批量快照轮询；动态间隔：连续竞价 `QTV_POLL_SEC`（3s）/ 休市 60s；超时 5s、连续 3 败熔断 60s 切东财；GBK 解码、字段位映射（快照字段 9–28 = 五档买卖盘）、科创板 688 成交量 ÷100 归一。
- **交付物**：`adapters/tencent.py` + 备源 `adapters/`（东财）。
- **验收标准**：真实响应样本 fixtures 的解析断言；间隔切换与熔断状态机测试；688 量纲用例。

### T06-2 规范化与 MarketBus
- **内容**：统一快照结构（五档/累计量/最新价/昨收/停牌标志）；当日累计成交量差分 = 周期增量 ΔV（撮合量约束基数）；MarketBus 内存最新档（WS 广播与引擎消费源）；新鲜度时钟（>30s 标记，供市价单拒单 `STALE_QUOTE`）。
- **交付物**：规范化层 + MarketBus。
- **验收标准**：ΔV 差分正确（跨 tick）；停牌标志透出；新鲜度判定用例。

### T06-3 三级降级链
- **内容**：腾讯 → 东财 → 内置锚点 FallbackProvider（`adapters/fallback.py`）；指数退避；`source/live` 状态透出；降级模式无盘口与 ΔV → 通知消费方回落 fallback 撮合档（联动 [T03-10](T03-撮合引擎.md)）。
- **交付物**：降级链调度。
- **验收标准**：mock 各级失败的三级切换测试；状态透出与恢复回切用例。

### T06-4 KlineSyncer（日K）
- **内容**：启动拉取全量历史（数千根一次性入库，后台任务不阻塞 lifespan）+ 每日 16:00 增量；`klines` 表幂等写入。
- **交付物**：KlineSyncer。
- **验收标准**：全量/增量重复执行不产生重复行；增量缺失日的补拉用例。

### T06-5 分钟线逐日累积
- **内容**：收盘任务将当日分时落 `minute_klines`（Q8 决议：自部署日起累积，历史不回补）；写入点由 [T08 日切序列](T08-会话服务与日切.md)调用。
- **交付物**：分钟线落库服务。
- **验收标准**：落库无重复（主键约束）；跨日累积用例。

### T06-6 公司行动采集
- **内容**：每日收盘任务拉取次日除权除息与分红送配方案 → `corporate_actions` 表（含 `source` 标注）；处理动作在 [T08-3](T08-会话服务与日切.md)。
- **交付物**：采集器 + 入库。
- **验收标准**：样本方案解析（每股派息/送股比/转增比/登记日/除权日）断言；重复拉取幂等。

### T06-7 交易日历推定
- **内容**：交易日期由快照时间戳推定（`trading_date`），写入 `sync_state` 供 T08 日切判定；非交易日/节假日推定用例。
- **交付物**：日历推定模块。
- **验收标准**：跨交易日边界（>0 点、开盘前）推定一致；节假日快照缺失时维持前值。

### T06-8 关注代码集动态
- **内容**：关注集 = 全体交易员持仓 ∪ 全体计划标的池 ∪ 指数；集合变化时通知 Poller 重订批量请求。
- **交付物**：关注集计算与订阅联动。
- **验收标准**：新建持仓/计划后下个轮询周期包含新代码；删除后退出。
