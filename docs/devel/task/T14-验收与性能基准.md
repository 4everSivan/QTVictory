## 1. 目标与范围

对照 02 §6.12 全表做终验收与性能基准，产出验收报告，补全 README 快速开始命令。本任务以**清点与补漏**为主：引用各任务的断言台账核对，发现缺项回填对应 task（走变更记录），不静默修补。

## 2. 任务明细

### T14-1 引擎/计划/策略单测清点
- **内容**：按 §6.12 清点 [T03](T03-撮合引擎.md)/[T04](T04-计划引擎与策略模板.md) 断言台账：五档逐档吃单与加权均价、量约束分批与部分成交累计、限额池多交易员竞争、集合竞价单价格撮合、科创板 1 股递增申报、±2% 有效申报范围、资金/持仓冻结与解冻、公司行动（分红税率/送转股数与成本摊薄/到账当日可卖，台账在 [T08-3](T08-会话服务与日切.md)）、四类触发器路径、风控熔断、策略围栏四道闸。
- **交付物**：勾稽表（断言项 ↔ 用例 ↔ 结果）。
- **验收标准**：逐项勾稽无缺漏；缺项回填登记。

### T14-2 API 完备性验收
- **内容**：复跑鉴权矩阵（有/无 Key、PUBLIC_READ）、幂等重放、限速 429、审计断言（[T09](T09-REST与鉴权幂等.md) 各条目）。
- **交付物**：验收执行记录。
- **验收标准**：§6.12 对应项全绿。

### T14-3 UI↔API 对照清单
- **内容**：以 [T09-8](T09-REST与鉴权幂等.md) 清单为基础，对照 [01 §7.2](../design/01-前端设计方案.md) 逐项验证"每项 UI 能力对应一个通过的 API 用例"（防能力漂移，§6.12）。
- **交付物**：对照清单终版（随验收报告归档）。
- **验收标准**：无缺口；发现漂移回填 T09/T10 变更记录。

### T14-4 生命周期验收
- **内容**：复跑任意资金创建 / 暂停 / 关闭 / 软删 / 硬删 / 注资 / 重置全流转（[T05](T05-交易员服务.md)）。
- **交付物**：执行记录。
- **验收标准**：全流转通过。

### T14-5 性能基准
- **内容**：四项指标（§2.3，本机口径）：① 64 交易员 × 2 计划 × 5 条件单单 tick 评估 < 50ms；② 导出 1 万行 < 2s（并记录 Q5 升级条件余量）；③ tick → 撮合/计划评估 → WS 广播 < 200ms；④ 接口 P95 < 50ms。记录实测值与测试环境。
- **交付物**：基准脚本 + 数据报告。
- **验收标准**：四项达标；不达标项给出瓶颈定位与优化建议（不阻塞报告归档，单独跟踪）。

### T14-6 验收报告与收尾
- **内容**：汇总 T14-1~5 为验收报告，归档 `docs/devel/report/`（目录随报告创建）；补全 [README](../../../README.md) 快速开始命令与进度表状态。
- **交付物**：`docs/devel/report/01-M8-验收报告.md` + README 更新。
- **验收标准**：报告含全部勾稽表与基准数据；README 与实际一致。
