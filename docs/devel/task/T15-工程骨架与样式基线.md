## 1. 目标与范围

建立 `frontend/` 生产工程：Vite + React 18 + TypeScript（strict）骨架、01 §10.1 目录映射、§3 设计令牌与双主题体系、§2.2 一屏五区栅格外壳、测试与工程基建。**本任务不含任何数据对接与业务组件**（数据层归 T16）；原型（`reference/design/demo/`，React UMD + Babel standalone）仅作样式/几何参照，代码不直接搬运，以 TS 改写。

范围外声明（01 §12）：移动端适配、浅色模式、自选股编辑——均不进本任务。

## 2. 任务明细

### T15-1 仓库与构建骨架
- **内容**：`frontend/` 建 Vite（react-ts 模板）；TS strict 全开；目录按 01 §10.1 落地：`src/components/charts/`、`src/components/panes/`、`src/components/traders/`、`src/api/`（占位）、`App` 视图层；包管理锁文件入库；`dev / build / test / preview` 脚本。
- **交付物**：可 `vite build` 通过的空壳工程 + 锁文件。
- **验收标准**：空壳构建零报错零警告（TS strict）；目录与 §10.1 映射逐项一致；锁文件提交。

### T15-2 设计令牌与全局样式
- **内容**：01 §3.2 Nothing 基线令牌全量转 CSS 变量（`--black/--surface/--raised/--line/--line2/--txt/--txt2/--txt3/--up/--down/--warn` + dim rgba 12%）；字体三族加载策略（Doto 仅现价 36px+ / Space Grotesk 正文 / Space Mono 全部 `.num`，中文回退 PingFang）；字号 ≤3 档、圆角 4/8/12/999、间距 8px 基数、动效 150–250ms `cubic-bezier(.25,.1,.25,1)` 仅透明度/边框亮度；语义色纪律 `.up/.down/.flat` 作用于数值本身、组件选择器禁止声明 color（§3.2 v1 固化坑）；`tabular-nums` 全屏数值。
- **交付物**：`src/styles/tokens.css` + 全局基础样式。
- **验收标准**：令牌表逐变量核对一致；三族字体在断网降级策略下不阻塞渲染（font-display 或本地自托管，实现时定并记录）。

### T15-3 双主题体系
- **内容**：§3.1/§3.3 Nothing 深色基线 + 终端深蓝备选两套令牌作用域切换（`data-theme` 或等价机制）；`window.__THEME` 图表主题钩子（§3.1，供 T18 消费）；主题持久化 localStorage（§9 UI 态仅此与上次选中交易员可入 localStorage）。
- **交付物**：主题切换模块 + 两套令牌。
- **验收标准**：切换即时生效无闪烁；刷新后主题保持；`window.__THEME` 可被外部读取且与当前主题一致。

### T15-4 布局栅格外壳
- **内容**：§2.2 CSS Grid 一屏五区：`grid-template-rows: 48px minmax(0,1fr) 236px` / `columns: 262px minmax(0,1fr) 324px`；topbar 通栏、leftcol 跨 2–4 行、center、rightcol、dock 跨 2–-1 列；左栏 55%/44% 分割；≤1180px 降级（左 220 / 右 300）。各区放占位 pane（标注区域名），不含业务内容。
- **交付物**：`App` 栅格外壳 + 占位组件。
- **验收标准**：1560×940 下几何与 §2.2/参考几何一致（dev 目检 + 截图留档）；≤1180px 降级生效；窗口缩放无溢出/错位。

### T15-5 测试与工程基建
- **内容**：vitest + @testing-library/react + jsdom；组件/纯函数测试示例各一；环境变量注入框架（§10.2：`VITE_API_BASE` 默认 `http://127.0.0.1:8787/api`、`VITE_API_KEY`，`.env` 不入库、样例入库）；CORS 联调说明（后端 `QTV_CORS` 放行 dev 端口）。
- **交付物**：测试基建 + env 约定 + README（frontend/ 局部，含启动命令）。
- **验收标准**：示例测试全绿；`VITE_API_BASE` 注入生效（打印/断言）；README 命令可复现空壳启动。
