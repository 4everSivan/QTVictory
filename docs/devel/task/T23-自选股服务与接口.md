## 1. 目标与范围

后端自选股能力全量：watchlist 持久化、WatchlistService（校验/幂等/审计）、REST 端点组（单码 PUT/DELETE、列表 GET、批量 POST、联想 suggest 代理）、关注代码集并入自选集、添加即异步引导日K。

明确不做：前端交互（归 [T24](T24-自选股编辑交互.md)）；分钟线历史回补（维持 Q8 决议边界）；自选标的的撮合/下单特殊校验（自选仅影响行情关注集，§3.10）。

## 2. 任务明细

### T23-1 watchlist 存储与服务
- **内容**：`watchlist(code TEXT PRIMARY KEY, added_at TEXT NOT NULL)` 建表并入 Schema 自动迁移（§6.2）；WatchlistService 提供 list（added_at 倒序）/ add / remove / batch 能力；单码幂等（重复添加返回原态、删除不存在视为成功）；代码校验 = 格式合法 + 行情源快照可达性；全部变更类操作写 `audit_log`（§3.3 口径）。
- **交付物**：`backend/app/services/watchlist.py`（服务）+ store 层迁移与读写方法。
- **验收标准**：迁移幂等（老库升级无损）；服务层单测覆盖幂等/校验/审计断言。

### T23-2 REST 端点组与批量回执
- **内容**：`GET /api/watchlist`（倒序列表）；`PUT /api/watchlist/{code}`、`DELETE /api/watchlist/{code}`；`POST /api/watchlist/batch` 接收 `{add:[], remove:[]}`，逐码校验、**部分应用**（合法码应用、非法码跳过）、逐码回执 `{code, ok, error}`；写操作接入幂等与限速中间件统一口径（§5.1）。
- **交付物**：API 路由与请求/响应模型。
- **验收标准**：逐码回执断言（混合合法/非法码批量请求）；幂等重放返回首次结果；审计落库逐条可查。

### T23-3 关注集并入与日K 引导
- **内容**：MarketService 关注代码集 = 自选 ∪ 持仓 ∪ 计划池 ∪ 指数（§3.4 v6）；自选删除后仍被持仓/计划引用的码保留关注集；新增自选成功后**异步**触发该码日K 引导（复用启动引导链：腾讯 ifzq → 东财 push2his 兜底）；批量添加的引导串行排队，引导失败不阻塞添加回执。
- **交付物**：MarketService 关注集计算修订 + 引导任务队列。
- **验收标准**：新增码次 tick 起 `quotes` 可见；删除后引用保留；引导触发与兜底链单测（ifzq 失败落东财）。

### T23-4 名称联想代理
- **内容**：`GET /api/market/suggest?q=` 代理腾讯 smartbox 联想（GBK 解码、字段规范化 `{code, name, kind}`、服务端短缓存 + 限速）。
- **交付物**：suggest 端点与适配器方法。
- **验收标准**：中文/拼音/代码三类查询实测返回规范化结果；缓存命中不重复外呼。
