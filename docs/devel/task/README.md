# 任务细化规格卡 (task/)

> **定位**: 每个功能模块的具体执行单元与最小交付卡片
> **状态**: Phase 1 所辖 22 项任务卡（T01–T22）**全部已交付验收**。

---

## 1. 任务卡规范

`docs/devel/task/` 汇集了系统开发过程中的原子任务卡片。每张卡片均严格包含：
1. **目标与范围**：清晰界定本模块的交付边界；
2. **任务细分条目**：原子级编码子项；
3. **完成定义 (DoD)**：可执行、可检验的退出门槛；
4. **设计↔任务映射**：回溯 [design/](../design/) 方案章节；
5. **变更记录**：记录开发过程中的设计妥协与落地细节。
