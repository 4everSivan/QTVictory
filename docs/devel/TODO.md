### 2.2 功能迭代规划 (Feature Roadmap)
来源：[01 前端设计方案 §12](design/01-前端设计方案.md) / [M16 报告 §7](report/02-M16-前端验收报告.md)。

- [ ] **自选股编辑（增删标的）** —— 需求已补全（2026-09-17 对抗性讨论确认）：
  - **语义**：关注集 = 自选 ∪ 持仓 ∪ 计划池 ∪ 指数（并集不变）；自选集前端置顶优先展示（按添加时间倒序），动态项（持仓/计划池驱动）不可删
  - **接口**（API-First，供 AI 程序化调用）：`GET/PUT/DELETE /api/watchlist/{code}` + `POST /api/watchlist/batch`（逐码校验、部分应用、逐码结果回执）；品种不限（个股/指数/ETF/可转债均可入自选）；添加即入轮询关注集并即时拉取该标的日K（不等次日增量）；观察员级
  - **交互**：左栏自选股头部 "+" 弹层，名称模糊联想搜索添加（接腾讯 sug 接口，源端不可用降级为代码直输）；列表项 hover 删除（仅自选可删）；用户主动添加的指数正常展示（覆盖现有指数过滤，仅动态集过滤指数）
  - **落地路径**：新功能，待立项后按 design 01 §12 第 3 条 / 02 §3.4 对应章节修订展开（plan/task 已封存，立项前不动代码）
- [ ] **移动端响应式布局**：针对平板/手机端屏幕做流式折叠适配
- [ ] **观察员审计日志查看界面**：后端审计数据（`audit_log`）已全量落库，前端增加可视审计日志面板
