# C006 - 按钮颜色继承重置缺失修复（交易员切换器名称黑字不可辨）

> **卡片ID**: C006 ｜ **类型**: BugFix ｜ **状态**: 核验通过
> **创建日期**: 2026-09-18 ｜ **关联设计**: [01-前端设计方案.md §3.2](../design/01-前端设计方案.md#32-设计令牌--nothing-基线)（另涉 §4.1 顶栏交易员切换器）

---

## 1. 变更背景与动因

- **Bug 表现**：深色模式下顶栏交易员切换器胶囊的交易员名称渲染为黑色，在深底上几乎不可辨（2026-09-18 人工截图实测确认）；下拉菜单项名称同病。
- **根因定位**：`<button>` 的 UA 默认样式 `color: ButtonText`（黑）不继承 body 的 `--txt`；v1/v2.1 原型有全局按钮重置 `button{font:inherit;color:inherit;...}`（见 `reference/design/demo/index-nothing-v2.html` L30），生产移植（T15 工程骨架）时该重置丢失。与 C005（滚动条样式丢失）同属"原型全局重置未移植"缺陷类。
- **影响面**：一切未显式声明 color 的按钮类元素——实测暴露的是 `.switcher-capsule` / `.switcher-item`（交易员切换器），其余按钮多数已在组件样式中显式声明颜色而未暴露。
- **为什么非改不可**：顶栏第一视觉焦点元素文字不可辨，且该缺陷类会随新按钮组件复发，须以全局重置根治。

| **代码/接口契约** | 生产 CSS 无按钮颜色重置，未显式声明 color 的按钮渲染 UA 默认黑色 | `base.css` 全局重置 `button { color: inherit }`，按钮文字随上下文令牌着色 | 元素选择器优先级最低，已显式声明颜色的组件样式（类选择器）全部不受影响；与"组件选择器禁止声明 color"纪律不冲突（该重置是 UA 默认归一，非语义色覆盖）。原型重置的 `font/background/border/cursor` 部分维持现状不动（组件样式已各自声明，避免全局改动引入视觉漂移），仅根治颜色缺陷 |
