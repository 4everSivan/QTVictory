# C004 - 主题收敛为单一 Nothing 深色套系（移除主题切换机制）

## 1. 变更背景与动因

- **现状**：设计 01 §3.1 定稿双主题机制（Nothing 深色基线 + 终端深蓝备选），顶栏提供 NOTHING/TERMINAL 切换按钮，令牌、图表主题、持久化、监听器全链路按双主题承载。
- **动因**（todo EN-0005，2026-09-17 登记，P1）：现行双主题均为过渡态、均不满意；视觉语言重设计已在 `todo/future.md` 另行登记。维护期保留两套套系 + 切换机制是纯负担，收敛为单一主题可砍掉约半套令牌与全部切换/持久化机制。
- **保留套系定夺**：按 EN-0005 登记建议采用 **nothing-dark**（现行基线，改动面最小）；2026-09-18 经人工明确点选确认（会话原话"主题收敛最终保留哪一套风格？"→"nothing（纯黑）"）。澄清：取舍对象是 nothing 风（纯黑）与 terminal 风（深蓝）两套深色风格的去留，与浅色无关。
- **联动影响**：[C002](C002-浅色主题细节接入.md)（浅色套系补全）——其 §1 预写作废条件（主题收敛先行落地且保留套系为深色）已被本卡触发，但**是否关闭 C002 由人工另行定夺，本卡不代为处置**；C002 维持待核验。
