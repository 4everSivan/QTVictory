# C007 - 按钮重置全量对齐原型口径（font/background/border/cursor）

> **创建日期**: 2026-09-18 ｜ **关联设计**: [01-前端设计方案.md §3.2](../design/01-前端设计方案.md#32-设计令牌--nothing-基线)

## 1. 变更背景与动因

- **背景**：C006 修复按钮 UA 默认黑字时只补回了原型按钮重置的 `color: inherit` 部分；原型完整重置为 `button{font:inherit;color:inherit;background:none;border:none;cursor:pointer}`（`reference/design/demo/index-nothing-v2.html` L30），其余四项（font/background/border/cursor）生产仍未移植——当前按钮渲染系统字体而非 Space Grotesk 字体栈，属同一"原型全局重置未移植"缺陷类的剩余部分。
- **人工指示（2026-09-18 会话）**："需要对齐原型口径"——将按钮重置补齐为原型完整口径。
- **为什么非改不可**：按钮字体栈与设计三族纪律不一致（系统字体混入），且 UA 默认背景/边框使未显式声明样式的按钮呈现原生外观，偏离 Nothing 扁平基调。
