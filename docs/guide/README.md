# QTVictory 使用与运维指南 (guide/)

> **定位**: 面向系统使用者、量化策略开发者与运维人员的指南目录
> **适用版本**: v0.1.0（Phase 1 · 模拟底座与观察员控制台）

---

## 1. 目录说明

`docs/guide/` 汇集了面向终端用户与部署运维的实用手册。与面向底层研发与架构演进的 `docs/devel/` 分离，本目录聚焦于如何**安装环境、配置参数、启动系统、操作控制台与安全卸载**。
