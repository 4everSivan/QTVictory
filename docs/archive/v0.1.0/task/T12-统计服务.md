## 1. 目标与范围

收盘净值快照与绩效指标计算（02 §3.8 统计侧 / §6.9）：总收益率、年化、最大回撤、夏普、胜率、超额 vs 沪深300，以及排行榜数据。指标基于真实 `equity_snapshots` 序列（不使用任何示意/合成数据）。

## 2. 任务明细

### T12-1 收盘结算快照
- **内容**：每交易日收盘对全体**未关闭**（running/paused）交易员落 `equity_snapshots`（日期/总资产/现金）；由 [T08-2](T08-会话服务与日切.md) 日切序列调用（顺序：日终撤单之后）。
- **交付物**：快照结算逻辑。
- **验收标准**：快照总资产 = 现金 + 持仓市值（按收盘价）口径核对；closed 交易员不落新快照；重置断点保留（联动 [T05-4](T05-交易员服务.md)）。

### T12-2 指标计算
- **内容**：总收益率 / 年化（因子 252）/ 最大回撤（回撤期天数 = 谷底距峰顶交易日数）/ 夏普 / 胜率（取卖出成交）/ 超额 vs 沪深300（基准 `klines(sh000300)`，源 [T06-4](T06-行情服务.md)）；**快照不足 2 日返回 null**。
- **交付物**：指标计算模块（保持纯函数化，便于 [T14](T14-验收与性能基准.md) 断言）。
- **验收标准**：构造已知序列的数值断言（手算对照）；<2 日 null 用例；超额基准对齐交易日。

### T12-3 排行榜数据
- **内容**：`GET /traders` 排行视图（`?status=running&include=closed&sort=ret`，§5.2）：按总收益率排序；closed 退出排行（历史可查）；数据供 WS `traders` topic 节流推送（[T10-2](T10-WebSocket与实时推送.md)）。
- **交付物**：排行查询服务。
- **验收标准**：排序/过滤参数组合用例；closed 交易员不在默认排行。
