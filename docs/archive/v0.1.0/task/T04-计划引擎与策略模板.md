## 1. 目标与范围

以**纯函数**实现计划触发评估、风控钩子、策略围栏与 8 个策略模板（02 §6.7）。触发器防重复等状态以"状态变更指令"形式输出，由 T11 在运行时落库回灌——本任务不持有任何可变全局状态。

## 2. 任务明细

### T04-1 PlanEngine 数据契约与纯度
- **内容**：输入：计划与条件单当前状态 × 行情快照/日K × 账户状态（持仓/现金/当日盈亏）；输出：触发意图（下单指令草案）、风控动作（暂停计划）、条件单状态变更（已触发/续期/到期）。
- **交付物**：`domain/plan_engine.py` 数据契约 + 纯度检查测试。
- **验收标准**：零 I/O、零框架依赖；契约覆盖四类触发器与风控所需的全部输入。

### T04-2 四类条件单触发器
- **内容**：`price_cross`（last 与阈值比较，单次触发防重复）、`pct_change`（当日相对昨收）、`time`（每交易日一次）、`ma_cross`（日K收盘口径）；参数非法返回 `BAD_TRIGGER`；有效期 `day | gtc`。
- **交付物**：触发器纯函数组。
- **验收标准**：§6.12 四类触发器路径断言；防重复（同条件二次 tick 不再触发）；`BAD_TRIGGER` 用例。

### T04-3 风控钩子
- **内容**：止损/止盈以**移动加权成本**为基准；日亏损（已实现 + 浮亏）达 `daily_max_loss` → 计划转 `paused` + `risk_halt` 事件指令。
- **交付物**：风控纯函数。
- **验收标准**：§6.12 风控熔断断言；止损止盈基准成本口径用例（部分成交摊薄后）。

### T04-4 策略围栏四道闸
- **内容**：策略/触发意图依次过闸：scope（标的池内）→ budget（资金预算）→ position_rule（仓位目标）→ 单笔上限；越闸拦截并给出 `PLAN_CONSTRAINT` 语义的拒绝原因。
- **交付物**：围栏过滤纯函数。
- **验收标准**：§6.12 策略围栏四道闸断言（逐闸拦截、全过放行）。

### T04-5 8 个策略模板
- **内容**：趋势跟踪 / 均值回归 / 网格 / 动量突破 / 长线价值 / 短线快进 / 事件驱动 / 保守配置；参数 schema 与前端 v1 §8 一致；输入行情/持仓，输出下单意图（经 T04-4 围栏）。定位：平台功能验证与绩效基线，非产品内容（§3.5）。
- **交付物**：`domain/strategies.py` + 模板注册表。
- **验收标准**：每模板至少覆盖涨/跌/震荡三类样本的决策路径用例；参数 schema 校验用例。

### T04-6 单测组织与断言台账
- **内容**：按 §6.12 建立"断言项 ↔ 用例名"对照台账；内核分支覆盖目标（stmt 覆盖率报告）。
- **交付物**：台账文档（测试模块 docstring 或独立清单）。
- **验收标准**：台账可追溯；[M2 退出条件](../plan/M2-领域内核.md)中计划相关项全绿。
