## 1. 目标与范围

交付行情展示三件套 + 顶栏市场状态区：自选股列表、个股头部、盘口五档与逐笔成交，全部经 [T16](T16-数据层与API客户端.md) 消费真实后端行情（REST 初始 + `quotes` topic 增量），行情降级时按 §4.6 显示 `DEGRADED` 状态条。

范围外声明：自选股编辑（增删标的）为 01 §12 候选项，**本任务不实现**，仅在列表结构预留扩展位。

## 2. 任务明细

### T17-1 自选股列表
- **内容**：§4.2 版式（`grid 1fr 76px 60px`）、涨跌闪动、选中左白条、底部涨跌统计条；数据接 `/market/quotes` + `quotes` topic；选中标的写入 UI 态（当前选中，§9），联动个股头部/图表区/下单面板。
- **交付物**：`components/panes/WatchList.tsx`。
- **验收标准**：数据来自后端真实行情；tick 更新闪动不整行重排（键稳定）；选中态切换联动全局；空数据/降级态有占位。

### T17-2 个股头部
- **内容**：§4.4 v1 定稿不变：Doto 36px+ 现价 + 8 项指标 chips；数据源 `/market/quotes`；涨跌语义色作用于数值本身（§3.2 纪律）。
- **交付物**：`components/panes/QuoteHeader.tsx`。
- **验收标准**：现价/涨跌幅/八项 chips 与后端字段逐项一致；切换标的即时刷新；字体档位符合 §3.2（Doto 仅现价 36px+）。

### T17-3 盘口五档 + 逐笔成交
- **内容**：§4.6 版式（卖5→买1 降序 + 中价带 + 逐笔滚动区）；数据为后端透出的真实快照五档与逐笔（v1"模拟深度"合成废止、"· 模拟深度"标注移除）；行情降级（fallback）时五档区显示 `DEGRADED` 状态条；逐笔滚动最新在底。
- **交付物**：`components/panes/OrderBook.tsx`（含逐笔子区）。
- **验收标准**：五档档位/价格/量与后端快照一致；逐笔随 tick 追加滚动；fallback 状态条出现/消失与 T16-4 状态输出一致。

### T17-4 行情订阅编排
- **内容**：行情面板订阅生命周期管理：`quotes` topic 订退、`/market/kline`、`/market/minute` 初始拉取（图表区消费，本任务只负责在选中标的切换时触发预取并放入 T16 缓存）；标的切换时旧订阅清理。
- **交付物**：`hooks/useMarketSelection.ts`（或等价）。
- **验收标准**：切换标的无旧数据残留/无重复订阅；kline/minute 预取对 T18 可直读。

### T17-5 市场状态与指数胶囊
- **内容**：§4.1 顶栏左段：品牌区（红方块 + "模拟盘" + PAPER 胶囊）保留、市场状态胶囊对接 `GET /api/session`（交易中/已收盘/集合竞价/已降级）、沪深300 胶囊（指数并入"9px 标签 + 15px 数值"同构单元，§4.1 v2.1）；状态胶囊随降级状态变色（语义色纪律内）。
- **交付物**：`components/panes/TopbarStatus.tsx`（顶栏其余段归 [T19](T19-交易员模块.md)）。
- **验收标准**：四种会话状态正确呈现；`live/fallback` 映射状态徽标（§7.3）；指数数据与后端一致。
