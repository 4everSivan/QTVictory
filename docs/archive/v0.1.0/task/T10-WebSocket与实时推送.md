## 1. 目标与范围

订阅式 `/ws` 端点与五类推送通道（02 §5.3）。明确不做 Webhook（Q6 决议）；断线恢复策略为"客户端 REST 全量拉回再续订"，服务端不持有会话状态。

## 2. 任务明细

### T10-1 订阅协议
- **内容**：`{"op": "sub", "topics": [...]}`；topic 集：`quotes` / `traders` / `trader:{id}` / `plans` / `events`；推送帧 `{"topic", "data"}`；取消订阅与非法 topic 处理。
- **交付物**：WS 端点与订阅管理。
- **验收标准**：订阅/退订生效；`trader:{id}` 按 id 订阅；非法 topic 明确错误帧。

### T10-2 五类推送通道
- **内容**：`quotes` 每 tick（源 MarketBus）；`traders` 排行节流 2s + 生命周期事件；`trader:{id}` 单交易员账户/成交/冻结变动；`plans` 事件（`entry_triggered / risk_halt / plan_done`，M6 接入后生效）；`events` 全局动态流水（源 [T05-5](T05-交易员服务.md)）。
- **交付物**：通道分发层。
- **验收标准**：各 topic 推送内容与源头一致；`traders` 节流 2s 断言（突发下合并推送）；`plans` 通道预留可验证（测试事件注入）。

### T10-3 握手鉴权
- **内容**：复用 [T09-4](T09-REST与鉴权幂等.md)：`?key=` 或 `Sec-WebSocket-Protocol`；免鉴权模式下放行。
- **交付物**：握手校验。
- **验收标准**：有/无 Key × 握手方式的矩阵用例；Key 错误拒绝握手。

### T10-4 连接生命周期
- **内容**：心跳 ping/pong；断开时清理订阅；服务端支持客户端"REST 拉回再续订"恢复模式（无服务端会话状态依赖）。
- **交付物**：连接管理。
- **验收标准**：断连后订阅清理（无泄漏）；重连重订后推送恢复；tick → 推送的冒烟延迟记录（正式基准归 [T14-5](T14-验收与性能基准.md)）。
