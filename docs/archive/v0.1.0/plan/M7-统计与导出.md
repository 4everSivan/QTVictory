## 1. 目标

量化底座的"评估出口"：收盘净值快照 → 绩效指标（收益率/年化/回撤/夏普/胜率/超额）→ 排行榜；以及五类数据 × 双格式 × 区间过滤的导出。

## 2. 退出条件

- [ ] 指标数值断言通过：年化因子 252、回撤期天数口径（谷底距峰顶交易日数）、胜率取卖出成交、超额 vs 沪深300、快照不足 2 日返回 null；
- [ ] 排行榜按总收益率排序，`closed` 交易员退出；
- [ ] 导出五类（trades/orders/positions/equity/plans）× csv/json 全组合通过字段与内容断言；
- [ ] CSV 兼容：UTF-8 BOM、金额两位小数无千分位、Excel 可直接打开；
- [ ] `Content-Disposition` 附件下载行为正确；`EXPORT_RANGE_INVALID` 参数校验；
- [ ] 区间过滤边界用例（from/to 含/不含边界）通过。
