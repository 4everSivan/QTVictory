## 1. 目标

交付一个**可启动、可测试的空系统**：FastAPI 应用装配、`QTV_*` 配置加载、SQLite 建库与迁移、pytest 测试基建、单一事件循环串行化基座。本里程碑不含任何业务功能。

## 2. 退出条件

- [ ] `uvicorn` 启动，`GET /health` 返回 200，仅监听 `127.0.0.1:8787`（`QTV_PORT` 可改）；
- [ ] 空库启动自动完成全部建表迁移，`PRAGMA journal_mode` 确认为 WAL；
- [ ] 02 §6.10 全部 10 项配置项可注入覆盖且默认值与设计一致；
- [ ] pytest 全绿，三层测试目录（纯函数 / 服务 / 集成）约定就位；
- [ ] 串行化基座单测通过：并发提交的状态变更严格按到达顺序执行。
