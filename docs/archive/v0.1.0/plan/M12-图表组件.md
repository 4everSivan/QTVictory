## 1. 目标

交付 01 §5 全章规格的三个纯 SVG 主题化图表组件：日 K（§5.1 全交互）、分时（§5.2）、净值曲线（§5.3，含 TradersCurve 可选对比组件）+ 图表基础设施（渲染框架、`window.__THEME` 主题消费、§5.4 三重测量兜底）。组件为纯展示：数据经 props/M10 缓存注入。

## 2. 退出条件

- [x] §5.1 交互逐项可用：90 根默认 / 滚轮缩放 30~N（×1.18）/ 拖拽平移 / 双击复位 / MA 透明度阶梯 / 最新价虚线右轴标签 / 十字光标 OHLC 条；
- [x] §5.2 分时逐项可用：242 槽 / 双轴 / 涨跌色 + 5% 面积 / VWAP 虚线 / 昨收基准 / 量柱 22%；
- [x] §5.3 净值曲线：归一化百分比双线 + 悬停浮签四字段；<2 日空态 `--` + "数据积累中"；
- [x] 双主题下三图表配色正确切换（`window.__THEME` 钩子生效）；
- [x] §5.4 三重测量生效：RO + 直接测量 + 定时/resize 兜底（jsdom 以固定尺寸走兜底路径验证）；
- [x] 缩放/平移/归一化/VWAP/槽位映射纯函数单测全绿（87 用例）；视口裁剪实现，大视口帧率实测归 T22-4。
