## 1. 目标

首批**有状态服务**落地：交易员全生命周期管理（T05）；真实行情接入、三级降级链与 MarketBus 出数（T06）。完成后系统具备"人"和"数据"，但尚不能交易。

## 2. 退出条件

- [ ] 交易员生命周期全流转测试通过：任意资金创建（含模板实例化）/ 暂停 / 恢复 / 关闭 / 软删 / 硬删 / 注资 / 重置（02 §6.12 生命周期项）；
- [ ] `QTV_MAX_TRADERS` 上限生效；
- [ ] 行情在真实上游下运行并通过样本 fixtures 解析断言（GBK / 字段位 / 688 量纲）；
- [ ] 降级链三级切换测试通过（mock 各级失败）：腾讯 → 东财 → 锚点，`source/live` 状态透出；
- [ ] MarketBus 输出规范化快照（含五档、ΔV、停牌标志、新鲜度时钟），关注代码集随持仓/计划池动态更新。
