## 1. 目标

三大领域内核——MatchingEngine（撮合）、PlanEngine（计划触发与风控）、Strategies（8 策略模板）——以**纯函数**形态完成，并用全量单测锁定 A 股规则。模块零 I/O、零框架依赖（02 §2.3 可移植、§4.1），这是全项目风险最高的部分，置于最前。

## 2. 退出条件

- [ ] §6.12 引擎相关断言全绿：五档逐档吃单与加权均价、量约束分批与部分成交累计、限额池多交易员竞争、集合竞价单价格撮合、科创板 1 股递增申报、±2% 有效申报范围、资金/持仓冻结与解冻；
- [ ] §6.12 计划相关断言全绿：四类触发器路径、风控熔断、策略围栏四道闸；
- [ ] 纯度检查通过：`domain/` 内模块不 import fastapi / sqlite / httpx；
- [ ] 内核对外接口（函数签名与数据契约）文档化，供 T07 / T11 集成。
