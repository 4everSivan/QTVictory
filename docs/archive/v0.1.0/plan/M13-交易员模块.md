## 1. 目标

交付观察员对交易员的全部 UI 能力（§8 纯展示 + 管理入口）：顶栏当前交易员切换器与五指标均分数据带（§4.1 v2.1）、交易员侧板与管理菜单（§4.3）、创建/编辑对话框（§4.10，模板参数 schema 驱动）、详情弹窗（§4.10 五区）。**切换器全站跟随语义在本里程碑全局生效**（§2.1 v2：持仓/委托/成交/收益分析与下单面板全部跟随）。

## 2. 退出条件

- [x] 切换器胶囊下拉（名称 + 模式徽标 + 总资产速览）可用，切换后五指标/Dock/下单面板全部跟随；无交易员空态"创建交易员"直达；
- [x] 五指标均分数据带按 v2.1：`flex:1` 等分、1px 细线分隔、窗口拉宽等距拉开；字号三档纪律落实；
- [x] 侧板排行/管理菜单（编辑/暂停·恢复/注资/导出/删除二次确认）/动态流/空世界引导按 §4.3 全落地；
- [x] 创建/编辑对话框接 `GET /api/templates`（8 模板 + 参数 schema 动态表单），任意初始资金与可选计划速设；
- [x] 详情弹窗 720px 五区（统计/净值/持仓/最近成交/计划页签容器）数据真实、`trader:{id}` 增量刷新；
- [x] 生命周期流转对真实后端冒烟通过（pause/resume/capital 实测；订阅无泄漏由 hooks 层去重保证）。
