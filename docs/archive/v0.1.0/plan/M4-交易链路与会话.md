## 1. 目标

打通**端到端交易闭环**（尚无 API 入口）：下单校验链 → 撮合引擎 → 成交/冻结落库 → 撤单；以及交易时段状态机与日切全序列（含公司行动处理）。完成后系统"能交易"，只差对外暴露。

## 2. 退出条件

- [ ] 下单校验链集成测试通过：成功路径 + §5.4 各拒单码（LOT_SIZE / PRICE_BAND 含双区间 details / INSUFFICIENT_FUNDS / T1_LOCKED / SESSION_CLOSED / STALE_QUOTE / 停牌）；
- [ ] 撮合集成正确：限价单跨 tick 分批部分成交、市价单五档加权、一单多笔 trades 落库；
- [ ] 撤单与解冻：可撤窗口（连续竞价与 9:15–9:20）内外行为正确；
- [ ] 时段状态机：一个完整交易日（集合竞价→连续竞价→收盘）的状态序列测试通过；
- [ ] 日切序列**幂等可重入**：中断重跑不重复入账；
- [ ] 公司行动数值断言通过（02 §6.12）：分红税率、送转股数与成本摊薄、到账当日可卖。
