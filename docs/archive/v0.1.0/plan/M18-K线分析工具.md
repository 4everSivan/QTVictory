## 1. 目标

落地 K 线可视化分析工具（来源：now.md FT-0009，2026-09-18 登记，2026-09-20 迁入立项；Q9–Q12 决议已确认）：后端建多周期 K 线数据底座——**冷热双态 bar 模型**（`kline_view` 冷热合成纯函数 + 换日捕获自沉淀 + 校准重拉兜底）、前复权口径明示锚定、日 K 引导深度 320 → 800 可配（`QTV_KLINE_DEPTH`，上限 800），以及 week/month 纯函数聚合与 `period` 枚举放行（minute 假参数已随 [C013](../../../devel/change/C013-修复kline接口period假参数.md) 移除）；前端 K 线图四周期 Tab（分时｜日K｜周K｜月K）、VOL/MACD/RSI/KDJ 副图槽位、MA/EMA/BOLL 主图叠加、指标色阶令牌与 golden vectors（D1–D8 定稿，D6 指标色阶为用户拍板）。画线工具（趋势线/水平线/斐波那契）二期占位，本期不做。

## 2. 退出条件

- **冷热双态四护栏**（02 §6.12 口径）：① `kline_view` 冷热合成纯函数单测（正常/降级缺 OHLC/停牌/停机跨换日→重拉兜底）；② 换日捕获源门禁断言（tencent/sina 必落、eastmoney 缺字段不落、anchor 恒不落）；③ 量纲锚定——收盘快照 `cum_volume` 与 ifzq 同日 volume 一致性实测断言（手/股口径）；④ 校准重拉深度 ≥ 库存深度约束断言；断点重入（崩溃于捕获与 checkpoint 之间幂等重跑）全过；
- **多周期聚合**：week/month 纯函数单测覆盖跨年周界、节假日短周、单交易日周、月末切分、`limit` 作用于聚合后根数、week 取数 5N+缓冲换算；离线注入（`sync_klines`）→ `/market/kline?period=week|month` 聚合正确性断言；
- **API 契约**：`period=day|week|month` 实测放行；非法值（含旧 `minute`）400 `BAD_REQUEST`；
- **深度配置**：`QTV_KLINE_DEPTH` 默认 800 上线生效；单源拉取失败回落 320 不阻断引导链；
- **前端**：四周期 Tab、副图槽位（VOL/MACD/RSI/KDJ 切换与阈值虚线）、主图叠加（MA/EMA/BOLL 独立开关）、图例（日期+OHLC+涨跌幅+指标当前值）、指标色阶令牌（ind3/ind4/ind5 深浅两套）与 golden vectors 单测；§5.1 交互定稿（滚轮/平移/双击复位/十字光标）对周 K/月 K 同样适用；
- **测试命令全绿**：`cd backend && pytest`、`cd frontend && npm test`、`npm run build`、`node frontend/scripts/e2e.mjs`；验收结论落 `report/` 新验收报告。
